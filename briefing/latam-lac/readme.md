# Latin America & Caribbean (LATAM-LAC) Cyberthreat Reports

This folder contains ZIP-packaged interactive cyberthreat intelligence reports focused on Latin America & the Caribbean, published by the **WXA Internet Abuse Signal Collective (IASC)**.

These packages are intended for analysts, researchers, network defenders, CERT/CSIRT teams, policymakers, and operational security stakeholders requiring structured regional threat intelligence and interactive reporting artifacts.

---

## Contents

Each ZIP package may include:

- Interactive HTML reports
- Threat intelligence dashboards
- Raw datasets and CSV exports
- Abuse signal summaries
- Network telemetry analysis
- Advisory documents
- Supporting visualizations and assets
- Technical readme documentation

---

## Recommended Usage

### 1. Download the ZIP package

Select the report package relevant to your analysis needs.

### 2. Extract the ZIP contents

Users should generally:

- Unpack the ZIP archive into a local directory
- Preserve the internal folder structure
- Open the included HTML reports locally in a modern browser

Recommended browsers:

- Google Chrome
- Microsoft Edge
- Firefox

---

## Important

Each ZIP package includes its own documentation and interpretation guidance.

After extraction, users should:

1. Read the package-specific README files
2. Follow the instructions for:
   - Interpreting the interactive reports
   - Reviewing advisories
   - Understanding raw data formats
   - Navigating dashboards and indicators
   - Using supporting assets and datasets

Different report packages may contain different methodologies, indicators, data schemas, or advisory structures.

---

## Notes

- Some reports may contain large datasets and may take several seconds to load locally.
- Interactive reports are designed for offline/local viewing unless otherwise specified.
- Preserve relative file paths after extraction to ensure dashboards and embedded assets function correctly.

---

## About the WXA Internet Abuse Signal Collective (IASC)

The WXA Internet Abuse Signal Collective (IASC) develops collaborative cyberthreat intelligence products and internet abuse monitoring resources focused on regional and sector-specific risk visibility.

These reports aggregate and contextualize internet abuse signals, malicious infrastructure observations, vulnerability trends, and operational threat intelligence relevant to Latin America & the Caribbean.
